⚡ QUICK START (4 STEPS)
════════════════════════════════════════════════════════════════════════════

STEP 1: Install Python Package (30 seconds)
─────────────────────────────────────────────
Open Terminal/PowerShell and type:
$ pip install anthropic


STEP 2: Get API Key (1 minute)
─────────────────────────────────────────────
1. Go to: https://console.anthropic.com
2. Click: API Keys
3. Click: Create Key
4. Copy the key (looks like: sk-ant-...)
5. In Terminal, type:
   $ export ANTHROPIC_API_KEY="sk-ant-..."


STEP 3: Prepare Your Requirements (5 minutes)
─────────────────────────────────────────────
Create file: my_requirements.txt

Example content:
───────────────────────────────────────────────
PROJECT: E-Commerce API

Build a REST API with:
- User authentication (JWT)
- Product catalog with search
- Shopping cart functionality
- Order processing
- Payment integration (Stripe)

TECHNICAL:
- Language: Node.js or Python
- Database: PostgreSQL
- Response time: < 200ms
───────────────────────────────────────────────


STEP 4: Run It! (15-30 minutes)
─────────────────────────────────────────────
$ python3 quickstart.py

Enter project name: My E-Commerce API
Enter project description: [Paste your requirements]

Then WAIT and WATCH!
The system automatically:
1. Analyzes your requirements (Task Manager)
2. Writes code (Developer)
3. Creates tests (Tester)
4. Plans deployment (Deployer)

Result: pipeline_results.json with everything!
