┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                    KEY DESIGN PRINCIPLES                                        │
├─────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                   │
│  1. SEQUENTIAL EXECUTION                                                                       │
│     • Agents execute one after another                                                         │
│     • Each agent waits for previous to complete                                               │
│     • Ensures proper context and dependencies                                                  │
│     • No parallel execution (simpler, more reliable)                                          │
│                                                                                                   │
│  2. CONTEXT PASSING                                                                            │
│     • Each agent receives output from previous stage                                          │
│     • Maintains coherent workflow across stages                                               │
│     • Each agent understands what came before                                                 │
│     • Reduces confusion and ensures consistency                                               │
│                                                                                                   │
│  3. AUTONOMY                                                                                    │
│     • No manual intervention once started                                                      │
│     • Agents make decisions independently                                                      │
│     • Error handling is automatic                                                              │
│     • Pipeline completes or fails gracefully                                                  │
│                                                                                                   │
│  4. QUALITY ASSURANCE                                                                          │
│     • Each stage validates previous work                                                       │
│     • Tests verify code quality                                                                │
│     • Quality standards enforced                                                               │
│     • Issues documented and reported                                                           │
│                                                                                                   │
│  5. TRANSPARENCY                                                                                │
│     • Full output from each agent available                                                   │
│     • Execution metrics tracked                                                                │
│     • Errors logged and reported                                                               │
│     • User can review at any time                                                             │
│                                                                                                   │
